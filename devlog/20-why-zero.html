Why the counter said zero

Nov 18, 2026·
  • website
  • debugging
  • docs

Right after launch, every number on the site was 0 or missing. There were three separate reasons.

First, the public counter answered with an error until the setting "allow using the visitor counter" was ticked. The page handles that by simply showing nothing, so nothing broke.

Second, GoatCounter stores paths without a trailing slash ("/devlog"), while our script asked for "/devlog/", so the list pages could never find their numbers. One line fixed it. While reading the docs I also found that screen size is meant to be sent as width, height and scale, not just the width.

Third, the docs say public counts are cached for up to four hours. Our first request got a 0, and that 0 stayed. Meanwhile the dashboard showed 10 real visits, two of them on EP.15. The numbers on the pages catch up later.

The lesson: read the documentation before guessing. Two of the three problems were written down there.
