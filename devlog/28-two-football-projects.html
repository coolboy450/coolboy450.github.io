Two football projects from before the studio

Nov 20, 2026·
  • other-projects
  • website
  • roblox

Before there was a studio or an AI team, there were side projects. Two of them are about football.

The first is Premier Live (September): a Premier League dashboard prototype with scores, tables, teams, news, search, favourites, notifications and a dark and light theme. Everything you see is demo data, and the page says so in a bar across the top and again in the footer. All data goes through one small layer, so switching to a real football data API later is a configuration change, with a note that the API key belongs behind a server, not inside the web page.

The player is the part I'm most glad about. By default it plays a simulated match drawn on a canvas with synthetic crowd sound. It can also play HLS, MP4 or an embed, but the settings say in plain words that it must be a stream you have the rights to publish, and the page links to the official place to watch. A football site that quietly embeds pirated streams is easy to build; this one was built to never need one.

The second is a football game for Roblox (October), two scripts and about 1,950 lines. The server script builds the pitch, goals, ball and lobby, then handles teams, positions and kits, shooting, passing, lofted passes, slide tackles, goalkeeper dives, skills, stamina, the score and a five-minute clock. The client script draws the controls and the HUD. To install it you paste two scripts into Roblox Studio, and you can test two teams with two local players.

The lesson: decide early where the honest line is (demo data, streams you have rights to) and put it in the product itself, not only in your head.
