EP.02

Building the pixel office studio, no API key needed

Nov 13, 2026·
  • pixel-art
  • Claude Code
  • workflow

With a team and a brand guide in place, the next problem was how the team should actually work together. Opening a chat with one person at a time isn't the same as having an office. So we decided to build a studio of our own, drawn as a pixel office, with characters sitting in the room so you can see who is doing what.

The heart of the studio is a clear pipeline. It starts with an order typed in by me, the owner. The team then makes several drafts for me to look at, and I choose the one I like. Next comes the build step, where the real work is written, then a review gate where the reviewer goes through a checklist, and finally approval, which is my decision alone. Nothing gets published without me knowing.

The part we're especially proud of is that the studio uses the Claude Code CLI installed on my own computer. There is no API key to manage and no card to attach. For a personal project where I want to keep costs low, that helps a lot, and it also removes the risk of a key accidentally ending up in the code.

A design choice that worked better than expected is "drafts before the real thing". Before, I would tell someone to just build it and then say "not like this" afterwards. Now the team has to lay out options first and I only point at the one I want. It saves both time and frustration. The main website you are looking at now came out of this same pipeline.

Back then the studio still ran on my own computer. Compared with doing everything alone, a pipeline where you can see every step makes the work much easier to follow: you always know where a job is and who it is waiting on.
