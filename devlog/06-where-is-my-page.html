EP.06

The team said it was done, but I couldn't find the page

Nov 14, 2026·
  • stock-bot
  • debugging
  • lesson

For learning only. Not investment advice.

The team had finished the /monitor page and the price guard for the stock bot, the review said pass, and I approved it in the studio. Then I opened the link and got a 404. The page the team had built simply wasn't there.

The reason was almost boring: the bot's dashboard was still running the old code it had started with, long before the team began working. The files on disk had changed, but the running program hadn't been restarted, so it knew nothing about the new page. One restart later, the page appeared.

That made me check the work properly instead of just trusting the pass. I ran the real thing and found three bugs the review had not caught. The log panel stayed empty, because the code read the log level the wrong way and no log line ever reached the page. A yellow "data is stale" warning kept appearing after 15 seconds, even though the bot only sends its "still alive" signal every 30. And the worst one: two separate programs, the scheduler and the dashboard's "run now" button, each kept their own copy of the status file. Every 30 seconds the scheduler wrote its older copy over a round that "run now" had just finished, so the result vanished.

Each bug got a fix and a test that fails if the bug comes back (the test suite grew from 70 to 112 tests along the way). Then I pressed the button myself: the round showed up, and it was still there forty seconds later, after the scheduler had written again.

The lesson: "done" from a team of AIs means the code has been written and a checklist has passed. It does not mean the thing is running, or that it behaves when two parts touch the same file. Open the real page, press the real button, and wait long enough for the background jobs to fire.

This bot is still Paper mode only, so none of this involves real money. The next episode is about getting this page into the studio, so there is one place to open instead of two.
