EP.23

NVDA at 1,694 dollars

Nov 18, 2026·
  • stock-bot
  • incident
  • testing

While Bank worked, Discord lit up with "[PAPER] BUY 5 NVDA @ 1,694.91", four times. NVDA's real close the day before was 155.46.

The paper portfolio had not been touched: 0 orders, 0 trades, cash still 100,000. The bot's log showed test stocks called AAA and BBB being "bought" in the same minute. These were the bot's own tests, which Bank was running.

The cause: the bot's settings load the project's private settings file automatically, and that file holds the real Discord webhook. Anything an agent ran in that folder could post to the real channel.

What gave it away was a made-up price. A realistic fake price would have looked exactly like a real trade.

The lesson: tests must not be able to reach the real world. Secrets that load automatically will, sooner or later, load somewhere you didn't expect.
