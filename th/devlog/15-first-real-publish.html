EP.15

เผยแพร่จริงครั้งแรก กับช่องที่ต้องการแค่โดเมน

17 พ.ย. 2026·
  • แอปตัดต่อ
  • เผยแพร่
  • discord

โปรเจกต์แอปตัดต่อยังไม่มีที่ให้เผยแพร่ เลยได้ repository กับเว็บ GitHub Pages ของตัวเอง ให้ GitHub สร้าง repository ใหม่พร้อม README มาให้ เพราะตัวเผยแพร่ต้องมีอะไรให้ clone

การเผยแพร่ครั้งแรกถูกปฏิเสธ ซึ่งเป็นสิ่งที่ควรเกิด ใน EP.12 ตัวเผยแพร่ถูกสอนให้หยุด ถ้าโปรเจกต์ต่างจากของที่อยู่บน GitHub และไม่เคยเผยแพร่ที่นั่นมาก่อน จะได้ไม่ลบสิ่งที่มันไม่รู้จัก การลองแบบไม่ส่งจริงบอกชัดว่าจะเกิดอะไร เพิ่มสามไฟล์ และลบ README ตั้งต้น ตรงกับที่เราต้องการ เลยส่งไปพร้อมตัวเลือกที่บอกว่า "ใช่ นี่คือการเผยแพร่ครั้งแรก"

ราวยี่สิบวินาทีหน้าเว็บขึ้น 404 ระหว่างที่ GitHub Pages สร้างเว็บ แล้วก็ตอบกลับมา ตอนนี้แอปตัดต่ออยู่ที่ coolboy450.github.io/video-editor และโปรเจกต์ถูกตั้งค่าไว้แล้ว ครั้งหน้ากดปุ่มในสตูดิโอได้เลย

จากนั้นผมจะเอาไปโชว์ในโปรไฟล์ Discord ช่อง "Connect your Domain" ไม่รับลิงก์เต็ม ขึ้นว่า "String value did not match validation regex" มันต้องการแค่ชื่อโดเมน coolboy450.github.io ซึ่งยืนยันไว้แล้วตั้งแต่ตอนเว็บหลักขึ้น Discord ยืนยันทั้งโดเมน ไม่ใช่ทีละหน้า โปรไฟล์เลยแสดงเว็บหลัก ส่วนลิงก์แอปตัดต่อไปใส่ในข้อความ About me

พูดตามจริงว่าอะไรยังค้าง การเผยแพร่ครั้งแรกนี้รันเป็นคำสั่ง ไม่ได้กดผ่านปุ่ม และยังไม่มีใครโหลดวิดีโอจริงเข้าแอปเลย ทั้งสองอย่างคือเรื่องถัดไป

บทเรียน: ตัวกันที่บอกว่าไม่ในการรันครั้งแรกกำลังทำหน้าที่ของมัน อ่านก่อนว่าทำไมมันหยุด ก่อนจะหยิบตัวเลือกข้าม
