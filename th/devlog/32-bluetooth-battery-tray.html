EP.32

ตัววัดแบตหูฟัง และเมาส์ที่อ่านไม่ได้

25 พ.ย. 2026·
  • windows
  • บลูทูธ
  • ซีซัน 2

เรื่องนี้เริ่มจากภาพหน้าจอ ผมตีกรอบมุมแถบงานแล้วถามว่า ถ้าถาดระบบโชว์แบตของหูฟังกับเมาส์ได้ล่ะ เรื่องเล็กๆ แต่แบตหมดกลางเกมหรือกลางสายเป็นเรื่องที่น่ารำคาญจริง

ก่อนจะสร้างอะไร ผมเช็กก่อนว่าเครื่องตัวเองบอกอะไรได้บ้าง Windows เก็บเปอร์เซ็นต์แบตของอุปกรณ์บลูทูธที่รายงานแบตไว้แล้ว เป็นตัวเลขเดียวกับหน้า Settings อ่านได้โดยไม่ต้องใช้ไดรเวอร์หรือสิทธิ์แอดมิน บนเครื่องผมมีอุปกรณ์เดียวที่มีค่า คือหูฟังสำหรับนอน 100% อุปกรณ์ที่จับคู่ไว้อีกสี่ตัวไม่มีค่า และหน้า Settings อธิบายเหตุผลได้ คือยังไม่ได้เชื่อมต่อ ส่วนเมาส์ไม่มีค่าเลย เพราะไม่ใช่บลูทูธ ใช้ตัวรับ USB 2.4 GHz และแบตของตัวรับแบบนั้นเป็นเรื่องของแต่ละยี่ห้อ ผมเลยกำหนดให้แอปบอกตรงๆ ว่า "ไม่ได้เชื่อมต่อ" กับ "ไม่รายงานแบต" เป็นคนละคำตอบ และไม่มีอันไหนที่เป็น 0%

เวอร์ชันแรกผิดแบบที่ผมจับได้จากการอ่านผลลัพธ์เท่านั้น มันรายงาน 100% ข้างชื่อ "Microsoft Bluetooth Enumerator" ไม่ใช่หูฟัง ค่าแบตอยู่บนโหนดบริการ และผมสมมติว่าโหนดแม่ของมันคืออุปกรณ์ ซึ่งไม่จริง โหนดของหูฟังเป็นพี่น้องกัน วิธีแก้คือจับคู่ด้วยที่อยู่ 12 หลักของอุปกรณ์เอง ตอนนี้มันแสดงหูฟัง 100% เหมือน Settings และอีกสี่ตัวเป็นไม่ได้เชื่อมต่อ

แอปเป็นไฟล์ C# ไฟล์เดียว ไม่ต้องลง SDK build ด้วยคอมไพเลอร์ที่มากับ Windows อยู่แล้ว โชว์แบตต่ำสุดเป็นตัวเลขบนไทล์สีเขียว ส้ม หรือแดง เตือนครั้งเดียวเมื่ออุปกรณ์เหลือ 40% หรือต่ำกว่า และเตือนใหม่หลังชาร์จเกิน 45% เปิดตอนเริ่ม Windows ก็ต่อเมื่อคุณติ๊กเอง เป็นโอเพนซอร์สบน GitHub: coolboy450/bt-battery-tray และการ build บน GitHub ผ่านแล้ว

สิ่งที่ตรวจแล้ว ตัวเลขตรงกับ Settings บนอุปกรณ์จริงหนึ่งตัว แอปรันต่อเนื่องได้ เปิดซ้ำแล้วตัวที่สองปิดเอง และ build ผ่านบนเครื่อง Windows ที่สะอาด สิ่งที่ยังไม่ได้ตรวจ ผมยังไม่ได้ดูไอคอนในถาดระบบบนหน้าจอจริง เลข "100" สามหลักอาจเล็กเกินไปที่ 16 พิกเซล ยังไม่เคยเห็นการแจ้งเตือนแบตต่ำขึ้นมา และอุปกรณ์ Bluetooth LE มีรองรับในโค้ดแต่ไม่เคยรันกับของจริง ส่วนเมาส์ อย่างที่บอก อ่านไม่ได้ และผมจะไม่เดาโปรโตคอลของยี่ห้อนั้น
