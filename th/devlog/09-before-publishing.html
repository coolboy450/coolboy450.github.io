EP.09

สองเรื่องที่ดีใจที่เช็กก่อนเผยแพร่

16 พ.ย. 2026·
  • เว็บไซต์
  • Discord
  • บทเรียน

สตูดิโอสร้างเว็บที่สองออกมาอีกอัน เป็นหน้า "บันทึก" กับหน้ารวมลิงก์ สำหรับ noob-dev.com ก่อนจะเอาไปไหน ผมอ่านว่ามัน "สัญญา" อะไรไว้บ้าง และมีสองอย่างที่ไม่เป็นจริง

อย่างแรกคือฟอร์มสมัครรับอีเมล พิมพ์อีเมล กดสมัคร แล้วเว็บตอบว่า "รับทราบ ฉบับหน้าเจอกัน" แต่ข้างหลังไม่มีอะไรเลย ไม่มีรายชื่อ ไม่มีเซิร์ฟเวอร์ ไม่ได้เก็บอะไรไว้ คนที่สมัครจะเชื่อว่าสมัครแล้วจริงๆ เราจึงเอาฟอร์มออก แล้วใส่กล่อง "ติดตามบน GitHub" แทน

อย่างที่สองอยู่ในหน้ารวมลิงก์ ปุ่มหลักเขียนว่า "เข้าเว็บ noobdev.com" โดเมนนั้น (ไม่มีขีด) มีอยู่แล้วและเป็นของคนอื่น ส่วนโดเมนที่ทีมใช้มาตลอด noob-dev.com ก็ยังไม่มีอยู่จริง ไม่มีใครซื้อไว้ และการซื้อโดเมนต้องเสียเงิน เว็บเลยไปอยู่บน GitHub Pages ฟรีแทน ตอนนี้ปุ่มเขียนว่า "เข้าเว็บ noob_dev" เฉยๆ

จากนั้นผมอยากเชื่อมเว็บเข้ากับโปรไฟล์ Discord แบบ "Domain" Discord ให้พิสูจน์ว่าเราเป็นเจ้าของโดเมนด้วยระเบียน DNS หรือไฟล์เล็กๆ ที่เปิดได้ที่ /.well-known/discord ที่อยู่แบบ github.io เป็นของ GitHub จึงใส่ DNS ไม่ได้ แต่วิธีไฟล์ทำได้ เราสร้าง repo พิเศษของ GitHub สำหรับบัญชีผู้ใช้ เพื่อให้ไฟล์นั้นอยู่ที่ราก และที่อยู่เดียวกันก็เสิร์ฟหน้าแรกของเว็บหลักด้วย

ส่วน Discord จะยอมรับที่อยู่แบบ github.io เป็นการเชื่อมต่อหรือเปล่า ผมยังยืนยันไม่ได้ ถ้าปฏิเสธ ทางสำรองฟรีคือเชื่อมบัญชี GitHub และทางที่เสียเงินคือซื้อโดเมนจริง

บทเรียน: ก่อนเผยแพร่ ให้อ่านทุกปุ่มและทุกฟอร์มเหมือนเป็นคำสัญญา แล้วถามว่ามีใครอยู่ข้างหลังมัน หน้าตาสวยๆ สัญญาของที่ไม่มีอะไรรองรับได้
