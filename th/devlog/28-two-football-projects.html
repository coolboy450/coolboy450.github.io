โปรเจกต์ฟุตบอลสองตัว ก่อนจะมีสตูดิโอ

20 พ.ย. 2026·
  • โปรเจกต์อื่น
  • เว็บไซต์
  • roblox

ก่อนจะมีสตูดิโอหรือทีม AI ก็มีโปรเจกต์ข้างๆ อยู่แล้ว สองตัวเป็นเรื่องฟุตบอล

ตัวแรกคือ Premier Live (กันยายน) ต้นแบบแดชบอร์ดพรีเมียร์ลีก มีสกอร์ ตารางคะแนน ทีม ข่าว ค้นหา รายการโปรด การแจ้งเตือน และธีมมืด/สว่าง ทุกอย่างที่เห็นเป็นข้อมูลจำลอง และหน้าเว็บบอกไว้ชัดทั้งแถบด้านบนและท้ายหน้า ข้อมูลทั้งหมดผ่านชั้นเล็กๆ ชั้นเดียว ถ้าจะเปลี่ยนไปใช้ API ข้อมูลฟุตบอลจริงก็แค่แก้ค่าตั้ง พร้อมหมายเหตุว่า API key ต้องอยู่หลังเซิร์ฟเวอร์ ไม่ใช่ฝังในหน้าเว็บ

ส่วนที่ผมภูมิใจที่สุดคือตัวเล่นวิดีโอ ค่าเริ่มต้นจะเล่นแมตช์จำลองที่วาดบน canvas พร้อมเสียงบรรยากาศสังเคราะห์ มันเล่น HLS MP4 หรือ embed ได้ด้วย แต่ในค่าตั้งเขียนไว้ตรงๆ ว่าต้องเป็นสตรีมที่คุณมีสิทธิ์เผยแพร่เท่านั้น และหน้าเว็บลิงก์ไปที่ช่องทางการสำหรับดูจริง เว็บดูบอลที่แอบฝังสตรีมเถื่อนสร้างง่าย แต่ตัวนี้ถูกสร้างมาให้ไม่ต้องใช้มันเลย

ตัวที่สองคือเกมฟุตบอลบน Roblox (ตุลาคม) สคริปต์สองไฟล์ ราว 1,950 บรรทัด สคริปต์ฝั่งเซิร์ฟเวอร์สร้างสนาม ประตู บอล และล็อบบี้ แล้วจัดการทีม ตำแหน่ง ชุด การยิง จ่าย จ่ายลอย สไลด์ ผู้รักษาประตูพุ่งรับ สกิล สแตมินา สกอร์ และเวลาแข่งห้านาที สคริปต์ฝั่งผู้เล่นวาดปุ่มควบคุมกับหน้าจอข้อมูล ติดตั้งด้วยการวางสคริปต์สองไฟล์ใน Roblox Studio และทดสอบสองทีมด้วยผู้เล่นสองคนในเครื่องได้

บทเรียน: ตัดสินใจให้เร็วว่าเส้นที่ซื่อตรงอยู่ตรงไหน (ข้อมูลจำลอง สตรีมที่มีสิทธิ์) แล้วใส่มันไว้ในตัวงาน ไม่ใช่แค่ในหัว
