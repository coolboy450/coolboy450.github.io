EP.24

อุดรอยรั่วที่สตูดิโอ

18 พ.ย. 2026·
  • สตูดิโอ
  • ความปลอดภัย
  • ทดสอบ

แก้ที่ต้นทาง ตอนสตูดิโอเรียกเอเจนต์ ตัวแปรลับทุกตัว (Discord, Telegram, LINE, โบรกเกอร์, API ข้อมูล) ถูกตั้งเป็นค่าว่าง และ webhook ของสตูดิโอเองถูกเอาออก ไลบรารีที่อ่านไฟล์ตั้งค่าลับจะไม่เขียนทับตัวแปรที่มีอยู่แล้ว ค่าว่างจึงชนะ

ตรวจบนเซิร์ฟเวอร์ด้วย Python ของบอทเอง ถ้าตั้งค่าว่างไว้ webhook ที่ได้ยาว 0 ตัวอักษร ถ้าไม่ตั้ง จะโหลดที่อยู่จริงยาว 121 ตัวอักษร

จากนั้นทดสอบด้วยเอเจนต์ปลอมที่จดว่าได้รับอะไรมา รอบแรกบอกว่าความลับยังอยู่ ต้นเหตุคือตัวทดสอบของผม ตอนสตูดิโอเริ่ม มันถามเวอร์ชันของเครื่องมือหนึ่งครั้ง การเรียกครั้งนั้นไปรันตัวปลอมแล้วเขียนไฟล์ก่อน พอข้ามการเรียกนั้น เอเจนต์ได้ค่าว่างจริง ไม่เห็น webhook ของสตูดิโอ และ PATH กับ HOME ยังอยู่ครบ

ลงเซิร์ฟเวอร์หลังงานของแบงก์หยุดรันแล้วเท่านั้น เพราะการรีสตาร์ตจะตัดงานกลางคัน

บทเรียน: เมื่อการแก้ "ไม่ได้ผล" ให้เช็กก่อนว่าการทดสอบวัดอะไรอยู่จริงๆ
