EP.25

ตัวตรวจที่บล็อกงานที่ถูก ด้วยเหตุผลที่ผิด

18 พ.ย. 2026·
  • สตูดิโอ
  • เผยแพร่
  • บั๊ก

การ์ดของแบงก์กลับมาว่า "ตรวจความปลอดภัยไม่ผ่าน 6 ข้อ" คือไฟล์ตั้งค่าลับ ไฟล์ฐานข้อมูลสามไฟล์ และเลขพอร์ตใน README กับในโค้ด dashboard

นี่เป็นบั๊กในตัวตรวจของสตูดิโอเองตั้งแต่ EP.12 งานโค้ดจะส่งเฉพาะไฟล์ที่ git เห็นว่าเปลี่ยน ไฟล์ที่ git ไม่สนใจอย่างไฟล์ตั้งค่าลับและฐานข้อมูลจึงไม่มีวันออกจากเซิร์ฟเวอร์ได้ แต่ตัวตรวจฝั่งสตูดิโอไปสแกนทั้งโฟลเดอร์

กฎพอร์ตมีไว้กันไม่ให้พอร์ตของเซิร์ฟเวอร์ไปโผล่บนหน้าเว็บสาธารณะ ในโค้ด ที่อยู่ dashboard ในเครื่องที่เขียนใน README เป็นเอกสารปกติ ตัวเผยแพร่ตัวจริงบล็อกเพราะข้อนี้ข้อเดียว

ตอนนี้สตูดิโอตรวจเฉพาะไฟล์ที่ git เห็นว่าเปลี่ยน ใช้กฎรายโปรเจกต์แบบเดียวกับตัวเผยแพร่ และกฎพอร์ตใช้แค่กับเว็บสาธารณะสองเว็บ ลองกับ repo ตัวอย่าง README ที่พูดถึงพอร์ตผ่าน ไฟล์ใหม่ที่มีที่อยู่เซิร์ฟเวอร์ถูกบล็อก หน้าเว็บที่โชว์พอร์ตของสตูดิโอถูกบล็อก จากนั้นงานของแบงก์ก็ผ่าน ตรวจ 8 ไฟล์ เทสผ่าน

บทเรียน: ตัวตรวจเดียวกันที่มีสองชุด สักวันจะเพี้ยนออกจากกัน ทำให้ชุดที่คนเห็นตรงกับชุดที่ตัดสินจริง
