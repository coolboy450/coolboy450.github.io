EP.02

สร้างสตูดิโอออฟฟิศพิกเซล ไม่ต้องมี API key

13 พ.ย. 2026·
  • พิกเซลอาร์ต
  • Claude Code
  • ขั้นตอนงาน

พอมีทีมกับคู่มือแบรนด์แล้ว ปัญหาถัดมาคือจะให้ทีมทำงานกันยังไง การเปิดแชทคุยทีละคนมันไม่เหมือนการมีออฟฟิศ เราเลยตัดสินใจสร้างสตูดิโอขึ้นมาเอง หน้าตาเป็นออฟฟิศพิกเซล มีตัวละครนั่งอยู่ในห้อง เห็นว่าใครกำลังทำอะไร

หัวใจของสตูดิโอคือสายงานที่ชัดเจน เริ่มจาก "สั่งงาน" ที่เรา เป็นเจ้าของพิมพ์ไว้ จากนั้นทีมทำ "แบบร่าง" ให้เราดูหลายแบบ แล้วเรา "เลือก" แบบที่ชอบ ต่อด้วยขั้น "ทำ" ที่ลงมือเขียนจริง ผ่านด่าน "ตรวจ" โดยผู้ตรวจตามเช็กลิสต์ และจบที่ "อนุมัติ" ซึ่งเป็นการตัดสินใจของเราคนเดียว ไม่มีอะไรหลุดไปเผยแพร่โดยที่เราไม่รู้

ส่วนที่เราภูมิใจเป็นพิเศษคือ สตูดิโอนี้ใช้ Claude Code CLI ที่ติดตั้งไว้ในเครื่อง ไม่ต้องมี API key ไม่ต้องไปผูกบัตรหรือจัดการคีย์ให้ยุ่งยาก สำหรับโปรเจกต์ส่วนตัวที่ยังอยากคุมค่าใช้จ่ายให้ต่ำ ข้อนี้ช่วยได้เยอะ และยังลดความเสี่ยงที่คีย์จะหลุดไปอยู่ในโค้ดโดยไม่ตั้งใจอีกด้วย

การออกแบบที่ได้ผลเกินคาดคือ "แบบร่างก่อนทำจริง" เมื่อก่อนเรามักสั่งให้ลงมือทำเลยแล้วค่อยมาบอกว่าไม่ใช่แนวนี้ ตอนนี้ทีมต้องวางทางเลือกให้ดูก่อน เราแค่ชี้ว่าเอาแบบไหน ช่วยประหยัดทั้งเวลาและความหงุดหงิด เว็บหลักที่คุณกำลังดูอยู่นี้ก็มาจากสายงานแบบนี้เหมือนกัน

ตอนนั้นสตูดิโอยังรันอยู่บนเครื่องของเราเอง เมื่อเทียบกับการทำทุกอย่างคนเดียว การมีสายงานที่เห็นทุกขั้นก็ช่วยให้ตามงานได้ง่ายกว่ามาก รู้ตลอดว่างานอยู่ตรงไหน และรอใครอยู่

ตอนต่อไปจะเล่าถึงด้านที่ไม่ได้อยู่ในแผนเลย คือการให้ทีมมีชื่อ มีนิสัย และงอนกันได้จริงๆ
