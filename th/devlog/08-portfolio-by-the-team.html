EP.08

เว็บพอร์ตโฟลิโอที่ทีมสร้าง และเราเป็นคนปิดงาน

14 พ.ย. 2026·
  • เว็บไซต์
  • การตรวจงาน
  • GitHub Pages

ผมอยากได้เว็บพอร์ตโฟลิโอ เลยสั่งทีมให้สร้างในสตูดิโอ มินท์ (นักออกแบบ UI) ส่งแบบร่างกลับมา 3 แบบ คือหน้าต่าง terminal ใบเดียว แบบแบ่งสองฝั่งพร้อมการ์ดโปรเจกต์ และแบบแถบแท็บสไตล์ tmux

พอเปิดแบบร่างจริง ความคิดของผมก็เปลี่ยนจากที่เดาจากคำอธิบาย แบบแบ่งสองฝั่งมีกล่อง "screenshot" ว่างอยู่ในทุกการ์ดโปรเจกต์ ทั้งที่เรายังไม่มีภาพหน้าจอจริงเลย เว็บจะดูเหมือนยังทำไม่เสร็จ ส่วนแบบ tmux แถบแท็บล้นจอตอนดูบนมือถือ ผมเลือกหน้าต่างใบเดียว แล้วยืมแถวตัวละครพิกเซลจากแบบ tmux มาใส่

บิตเป็นคนเขียน และครูแว่นตรวจตามเช็กลิสต์แบรนด์ ผู้ตรวจตีกลับ 3 เรื่องเล็กๆ ข้อความไทยในส่วนท้ายใช้ฟอนต์ Mono ซึ่งไม่มีตัวอักษรไทย เบราว์เซอร์เลยแอบสลับไปใช้ฟอนต์อื่น แว่นของครูแว่นสีเกือบเท่าสีหน้า (คอนทราสต์ประมาณ 1.4 ต่อ 1) และผมของป๊อปกับเสื้อของแบงก์สีเดียวกับหน้า ทำให้ตัวละครกลายเป็นก้อนสีเดียว

สตูดิโอแก้เองอัตโนมัติได้ 2 รอบ หลังจากนั้นส่งให้เจ้าของตัดสินใจ และผลตรวจก็ยังเป็น "ไม่ผ่าน" แต่บันทึกของผู้ตรวจละเอียดมาก ระบุถึงบรรทัดและค่าที่ควรใช้ เราเลยไม่ส่งทีมวิ่งอีกรอบ กดอนุมัติแล้วแก้ทั้ง 3 เรื่องด้วยมือ

เราตรวจสีใหม่ด้วยการคำนวณคอนทราสต์แทนการใช้สายตา แว่นได้ 11.3 ต่อ 1 ในธีมมืด และ 4.8 ต่อ 1 ในธีมสว่าง ส่วนผมกับเสื้อก็ต่างจากสีหน้าแล้วทั้งสองธีม จากนั้นเว็บขึ้น GitHub Pages ฟรี หลังสแกนหาของส่วนตัวแล้ว ไม่มีที่อยู่เซิร์ฟเวอร์ ไม่มีอีเมล ไม่มีลิงก์ภายใน

บทเรียน: ลูปตรวจงานอัตโนมัติเหมาะกับจับเรื่องเล็กๆ แต่มันหยุดหลังไม่กี่รอบ ถ้าเรื่องที่เหลือระบุได้ชัด คนเข้าไปปิดงานเร็วกว่าส่งวนอีกรอบ
