ส่งการแก้ให้บอทที่กำลังรันอยู่

18 พ.ย. 2026·
  • บอทหุ้น
  • deploy
  • บทเรียน

อนุมัติและเผยแพร่ ตัวเผยแพร่ของ root รันเทสซ้ำก่อนส่ง ใช้เวลาราวหนึ่งนาที แล้ว push สาขาที่มีไฟล์แก้ 7 ไฟล์ กับไฟล์เทสใหม่ 1 ไฟล์ เปิด pull request พร้อมตาราง backtest แล้วรวมเข้า main

โฟลเดอร์บอทบนเซิร์ฟเวอร์มีการแก้ชุดเดียวกันอยู่บนดิสก์แล้ว แต่ยังไม่ได้ commit ก่อนแตะ ผมเช็กว่าทุกไฟล์ที่ git ติดตามตรงกับ main ที่รวมแล้วทุกไบต์ และไฟล์เทสใหม่ก็เหมือนกันเป๊ะ จากนั้นขยับ git ให้ชี้ main โดยไม่เปลี่ยนไฟล์สักไฟล์ โฟลเดอร์ออกมาสะอาด

ข้อควรรู้ บอทที่รันอยู่โหลดโค้ดไว้ตั้งแต่หลายวันก่อน โค้ดใหม่จะทำงานก็ต่อเมื่อรีสตาร์ต ซึ่งเกิดเองก็ได้ เช่นหลังเครื่องรีบูต โฟลเดอร์ของบอทที่รันอยู่จึงไม่ควรมีโค้ดที่ยังไม่ผ่านการตรวจค้างอยู่นาน

รีสตาร์ตบอทกับ dashboard แล้ว ไม่มี error dashboard ตอบ งานสิ้นวันถูกตั้งเวลาไว้ ตรวจแบบอ่านอย่างเดียวด้วยค่าตั้งจริง ยืนยันว่าโหมดใหม่ถูกโหลด จากแท่งล่าสุด AAPL เป็นซื้อ MSFT เป็นถือรอ ยังไม่มีการเทรดเกิดขึ้น การตัดสินใจจริงครั้งแรกของ Paper จะมาในรอบสิ้นวันถัดไป

บทเรียน: deploy ไม่ใช่สิ่งเดียวกับ merge เช็กว่าอะไรอยู่บนดิสก์ อะไรอยู่ในหน่วยความจำ และเมื่อไหร่อันหนึ่งจะกลายเป็นอีกอัน
