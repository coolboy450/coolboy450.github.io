แผนสองแบบ และทำไมเลือกแบบเล็ก

18 พ.ย. 2026·
  • บอทหุ้น
  • แบบร่าง
  • ตรวจงาน

งานแก้ถูกส่งให้แบงก์ เป็นโหมด "เข้าตามแนวโน้ม" ที่ซื้อเมื่อเส้นเร็วอยู่เหนือเส้นช้า ราคาอยู่เหนือเส้นเร็ว และเส้นเร็วกำลังขึ้น พร้อมห้ามซื้อซ้ำ และรอห้าวันหลังโดน stop loss โจทย์ยังขอ backtest สองปีเทียบโหมดเก่ากับใหม่ และตารางที่ตรงไปตรงมาแม้โหมดใหม่จะแพ้

แบงก์เสนอสองแผน แบบ A ทำฟีเจอร์ cooldown ทั้งใน backtest และตัวเทรดจริง ตั้งค่า และเทส แตะ 5–6 ไฟล์ แบบ B ทุกอย่างของ A บวก helper กลาง สคริปต์เทียบผลที่รันซ้ำได้ README และตัวอย่าง แตะ 9–11 ไฟล์

เราเลือก A เพราะทำครบทุกข้อที่ขอ แตะไฟล์น้อยกว่าในโค้ดที่ตัดสินใจซื้อขาย ใช้โควตาน้อยกว่า และถอยกลับง่ายกว่า ของเพิ่มของ B ช่วยให้เป็นระเบียบ แต่ไม่ได้เปลี่ยนวิธีเทรดของบอท

โน้ตตอนเลือกขอตาราง backtest และหุ้นที่เข้าข่ายวันนี้ย้ำอีกครั้ง จะได้ไม่หลุดหายตอนแผนเล็กลง

บทเรียน: ในโค้ดที่ขยับเงิน แม้จะเป็นเงินสมมติ การแก้ที่เล็กที่สุดที่ทำงานได้ คือสิ่งที่ตรวจได้ปลอดภัยที่สุด
